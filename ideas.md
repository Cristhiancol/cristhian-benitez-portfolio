## Idea 1: "Neon Data Terminal" — Estética Cyberpunk / Data Dashboard

**Movimiento de Diseño:** Cyberpunk minimalista con influencia de terminales de datos y dashboards financieros.

**Principios Fundamentales:**
1. Fondo oscuro profundo (casi negro) con acentos de neón (cian eléctrico y verde lima).
2. Tipografía monoespaciada para datos y métricas, serif elegante para títulos.
3. Visualización de datos como elemento central del storytelling.
4. Microinteracciones que simulan "procesamiento de datos en tiempo real".

**Filosofía de Color:** Fondo #0a0a0f (negro azulado profundo) con acentos en cian (#00f0ff) y verde neón (#39ff14). El contraste extremo evoca pantallas de trading y terminales de datos, reforzando la identidad de "analista de datos". Toques de dorado (#ffd700) para logros y métricas clave.

**Paradigma de Layout:** Layout vertical tipo "scroll narrativo" con secciones full-width que alternan entre paneles de datos (con gráficos animados) y bloques de texto. Sidebar flotante con navegación tipo terminal.

**Elementos Distintivos:**
1. Contadores animados que "cuentan" las métricas de logros (11% ahorro, 20% reducción, etc.)
2. Línea de tiempo tipo "commit history" para la experiencia laboral
3. Partículas de datos flotantes en el fondo

**Filosofía de Interacción:** Hover effects que "iluminan" elementos como si se activaran circuitos. Scroll-triggered animations que revelan datos progresivamente.

**Animación:** Typing effect en títulos, contadores numéricos animados, partículas flotantes sutiles, transiciones de fade-in con desplazamiento vertical.

**Sistema Tipográfico:** JetBrains Mono para datos/métricas + Space Grotesk para títulos + DM Sans para cuerpo de texto.

</idea>

## Idea 2: "Supply Chain Blueprint" — Estética Industrial / Ingeniería

**Movimiento de Diseño:** Diseño industrial inspirado en blueprints técnicos y diagramas de flujo de cadena de suministro.

**Principios Fundamentales:**
1. Paleta basada en azul marino profundo (#1a2332) con blanco y acentos en naranja cálido (#ff6b35).
2. Líneas de conexión y diagramas de flujo como elementos decorativos.
3. Grid asimétrico que simula un plano técnico.
4. Datos presentados como "especificaciones técnicas" de un profesional.

**Filosofía de Color:** Azul marino (#1a2332) como base que transmite confianza y profesionalismo corporativo. Naranja (#ff6b35) como color de acción y llamada a la atención. Blanco (#f8f9fa) para contraste limpio. El azul evoca logística y comercio internacional; el naranja, energía y resultados.

**Paradigma de Layout:** Grid asimétrico con columnas de diferentes anchos. Secciones conectadas por líneas SVG animadas que simulan un diagrama de flujo de supply chain. Hero section con layout diagonal.

**Elementos Distintivos:**
1. Líneas SVG animadas que conectan secciones como un diagrama de flujo
2. Cards con esquinas cortadas estilo "blueprint"
3. Iconografía personalizada de logística (barcos, aviones, almacenes)

**Filosofía de Interacción:** Elementos que se "conectan" visualmente al hacer scroll, como si se completara un circuito de supply chain. Hover que revela detalles adicionales en tooltips estilo ficha técnica.

**Animación:** Líneas SVG que se dibujan al hacer scroll, cards que se deslizan desde los lados, números que se incrementan al entrar en viewport, transiciones suaves tipo "slide-in".

**Sistema Tipográfico:** Archivo Black para títulos impactantes + Source Sans 3 para cuerpo + Fira Code para datos numéricos.

</idea>

## Idea 3: "Executive Prestige" — Estética de Lujo Corporativo / Editorial Premium

**Movimiento de Diseño:** Editorial de lujo corporativo inspirado en revistas como Bloomberg Businessweek y reportes anuales de Fortune 500.

**Principios Fundamentales:**
1. Elegancia sobria con fondo claro cremoso y acentos en esmeralda oscuro (#064e3b) y dorado (#c9a84c).
2. Tipografía editorial con jerarquía dramática (títulos enormes, subtítulos refinados).
3. Espaciado generoso que transmite exclusividad y confianza.
4. Fotografía/imágenes de alta calidad como elementos de impacto.

**Filosofía de Color:** Fondo cremoso (#faf8f5) que evita el blanco puro y transmite calidez editorial. Esmeralda oscuro (#064e3b) como color principal que comunica crecimiento, finanzas y prosperidad. Dorado (#c9a84c) para destacar logros y métricas premium. Negro (#1a1a1a) para texto principal.

**Paradigma de Layout:** Layout editorial con secciones de ancho variable, algunas full-bleed y otras contenidas. Hero section con imagen de fondo y texto superpuesto con gradiente. Secciones alternas entre fondo claro y oscuro para crear ritmo visual.

**Elementos Distintivos:**
1. Métricas presentadas en "tarjetas de logro" estilo reporte anual con bordes dorados
2. Línea de tiempo elegante con marcadores circulares y líneas finas
3. Sección de habilidades como barras de progreso animadas con efecto shimmer

**Filosofía de Interacción:** Movimientos suaves y elegantes. Parallax sutil en imágenes de fondo. Hover effects refinados con transiciones de 0.4s. Nada brusco ni llamativo en exceso.

**Animación:** Fade-in elegante al scroll, parallax sutil, barras de progreso que se llenan suavemente, texto que aparece con efecto de revelación de izquierda a derecha, shimmer dorado en métricas.

**Sistema Tipográfico:** Playfair Display para títulos (serif elegante) + Outfit para subtítulos y navegación (sans-serif moderna) + Lora para cuerpo de texto (serif legible).

</idea>
